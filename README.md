# samhudson/tap

Homebrew tap for [Signals](https://github.com/samhudson/signals): your AI agent sessions, and what they use, in the macOS menu bar. Linux and Windows downloads are on the [releases page](https://github.com/samhudson/signals/releases/latest).

```bash
brew install samhudson/tap/signals
signals install
```

| Formula | Description |
|---|---|
| `signals` | Menu bar lights for your AI agent sessions (Claude Code, Codex, Cursor, Gemini CLI, Copilot), and their plan usage or cost |
